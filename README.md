# Churn Analysis Dashboard

## Description:

Developed a comprehensive and interactive Churn Analysis Dashboard to identify customer attrition patterns and provide actionable insights for reducing churn. The dashboard visualizes key metrics like total customers, churn rate, churn by gender, contract type, payment methods, service subscriptions, and demographic trends using interactive charts and slicers. It enables business stakeholders to make data-driven decisions to improve customer retention.

### Tools Used:

-   **Microsoft Excel** – Data cleaning and preprocessing
    
-   **SQL (SSMS)** – Data extraction and transformation (ETL operations)
    
-   **Power BI** – Data visualization and dashboard creation

### Problem Statement:

Understanding why customers stop using a service is crucial for improving retention. However, raw customer data alone doesn't reveal clear patterns or insights about churn behavior. This project aimed to explore and analyze customer churn using real-world data, identify key factors influencing churn, and create a visual dashboard to help interpret those trends in a meaningful and actionable way.

### Solutions Implemented:

-   **Data Integration & Cleaning:**
    
    -   Used Excel and SQL to clean, normalize, and prepare the raw customer churn using dataset of 6,400+ records data.
        
    -   Handled missing values, inconsistent formats, and created calculated fields (e.g., churn rate, tenure group).
        
-   **Churn Analysis Metrics:**
    
    -   Built KPIs including **Total Customers**, **New Joiners**, **Total Churn**, and **Churn Rate**.
        
    -   Segmented churn by **Gender**, **Payment Method**, **Contract Type**, and **Tenure Groups**.
        
-   **Customer Segmentation:**
    
    -   Identified high-risk churn groups using slicers (e.g., by marital status, monthly charge range).
        
    -   Highlighted churn-prone segments like **Month-to-Month contracts** and **Electronic Check payment users**.
        
-   **Visualization & Interactivity:**
    
    -   Created drill-down visuals for churn trends by year, tenure, and service categories.
        
    -   Enabled dynamic filtering and interactivity with slicers and tooltips to explore deeper insights.
